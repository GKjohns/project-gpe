- Size: 8,861 bytes (had to view it in two pieces; sections array is long, 50+ entries, most with 0 nodes).
- Learned: single main result `thm-main`: deterministic #k-CNF counting in (n+m)^{O_k(1)} 2^{O_k(n loglog n/sqrt(log n))} time, poly space; 2^{O_{k,D}(n/sqrt(log n))} when m<=Dn. Presumably Appendix D ("A sharper bound") carries the abstract's claim. Need to check which theorem is the real headline. Both are 2^{o(n)} so either refutes ETH.
- Friction: 71 friction notes for 89 nodes is alarming before I even start; `main_results` lists only thm-main although there are 3 theorems. The overview does not say which node is novel (would like `novel_nodes` list). The "proves" paragraph mentions tensor networks but the body sections (3-6) talk about polynomials/measurements/replacement forms; the vocabulary mismatch is confusing at first glance.
