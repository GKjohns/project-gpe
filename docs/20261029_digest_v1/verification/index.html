Project GPE v1: verification

Graphical Proof Explorer, Phase 1 (paper only). Implementation plan 20261029_digest_v1, executed Oct 29, 2026. Renamed from Digest the same day; screenshots taken before the rename show "Digest" in the header and titles.

What was built

From the browser, an operator pastes a GitHub directory or arXiv id (or uploads .tex), watches the run, then browses the paper as a tree, a dependency DAG, node pages with deep links, and a chat that cites nodes. The pipeline (fetch, deterministic LaTeX chunk, outline, extract, resolve, critique with a human review queue, annotate, classify, finalize) runs against a StepRunner: an in-process LocalRunner in dev and Inngest in production, with Drizzle over PGlite locally and Postgres by DATABASE_URL. Two structure methods were built and compared: a fixed pipeline (one whole-paper outline call) and a Claude Agent SDK agent in a Vercel Sandbox. Both ran over a nine-paper tiered corpus from a corpus page, and the numbers set the default: pipeline under 200k tokens.

Sprint 2: Ingest UI, source fetch, chunker, run page complete

GitHub directory, arXiv e-print and upload fetchers; a deterministic chunker that inlines \input, emulates \newtheorem counters and finds statements, proofs and refs; the New paper form and a live run page.

  • The plan expected 44 statements and 161 refs on ETH; the revised Oct 25 source has 36 statements (35 labeled) and 40 statement refs in proofs. Tests assert the real numbers.
  • lem:sparsify has no proof environment (Appendix A proves it), and thm:main has two titled proofs. Both became outline-prompt guidance.
  • Later fix (Sprint 8): a section titled "Proof of Lemma \ref{…}" now counts as that statement's proof (Rao, ALWZ).

Sprint 3: Outline (Method A), extract, resolve complete

One whole-paper Opus call outlines claims inside every proof of 60+ lines, extract writes each claim's statement, and resolve builds \ref edges plus model-inferred edges with a cycle guard.

  • Extract does not send the whole source as a cached prefix: through the gateway, auto-caching marks the last message, so a shared prefix never hit. Each claim gets a ±15-line window instead ($0.35 for 53 calls).
  • The outline prompt line-numbers the source (about 65k extra tokens on ETH) so spans are exact.
  • Later fix (Sprint 8): a paper's own \begin{claim} is kind lemma, not an outlined claim.

Sprint 4: Critique, annotate, classify, finalize complete

A whole-DAG critique call auto-applies fixes at 0.85+ confidence and queues the rest for a human; annotate writes names, plain statements and explanations dependencies-first; classify marks standard / routine / novel with a citation; finalize writes the digest and metrics. ETH end to end from the form: $3.59, 231 calls, 10 m 54 s.

  • root_ids ignores uses by corollaries and remarks; otherwise thm-main (used inside a corollary's proof) was not a root and the corollaries came first.
  • The review wait lives in ingestPaper outside any step, so the same code works under Inngest. The dev boot sweep fails waiting_review runs because their in-process waiter dies with Nitro.
  • Classify caps a paper at five novel nodes with one extra call (ETH: 6 to 5).

Sprint 4b: Agent structure method (Method B) complete

The outline step can instead boot a Vercel Sandbox from a snapshot, run a Claude Agent SDK agent that reads the proofs with shell tools and validates its own JSON, and stream its trace to the run page. On ETH (careful): 17 turns, $0.58, 50 claims in 11 proofs, the same shape as Method A.

  • The gateway key never enters the VM: the sandbox network policy injects the Authorization header for the gateway host.
  • A sandbox can't reach localhost, so dev polls the VM's trace.jsonl; the HTTP callback is used only with a public app URL.
  • Gateway usage arrives in message_delta, not message_start; the first ETH run under-counted running cost until both were read.
  • Every sandbox was stopped after every run, including cancels (checked with Sandbox.list).

Sprint 5: App shell, tree, node page, deep links complete

Dashboard layout with a paper tree (sections, statements, claims), node pages with KaTeX, breadcrumbs, share links, ⌘K search, and a collapsing sidebar on narrow screens.

  • Built against the toy fixture first; the ETH checks ran once Sprint 4 landed the digest. That surfaced \label inside display math and \mathds as KaTeX errors, now stripped or mapped.
  • The node page is keyed by paper, so moving between nodes keeps the sidebar, tree state and panel sizes mounted. select(id) pushes history so browser back walks the selection.

Sprint 6: Graph view complete

A layered dependency DAG (dagre) in the center panel with focus mode, a claims toggle, color by class or section, and a compact node card on the right, sharing selection with the tree.

  • dagre's default ranker floated leaves up and pinned orphans on the top row, so it read upside down. Ranks now come from graphRanks (longest path down to a leaf), with leaves tucked up under their lowest user.
  • The 400-node guard (default to Focus) was not exercised in the browser: no paper is that large.

Sprint 7: Chat and friction table complete

A streaming chat (Sonnet 5.5 through the gateway, digest in the instructions, cached) that cites nodes as [[id]], rendered as chips that drive the center panel; plus a plain friction table.

  • Citations are a Comark/markdown-it inline rule, not a text rewrite: the rewrite approach broke on "([[a]], [[b]])".
  • Comark's math rule refuses spans that start with a digit (a currency guard), dropping $2^{O(…)}$; those get a {} prefix.
  • Cost per turn on ETH: about $0.12 cold (writes the ~47k-token prefix to cache), $0.007–0.010 warm.

Sprint 8: Corpus page, metrics, method comparison complete

A manifest of nine papers in three tiers, goldens for the tier-1 paper and the toy, a corpus page that ingests each paper under both methods and shows the metrics side by side, and the default-method decision. Corpus spend for the sprint: $32.96 of the $80 cap.

  • The plan's PFR arXiv id (2311.05330) was a different paper; PFR is 2311.05762.
  • An empty UTable column header caused a hydration mismatch (found by bisecting).
  • The single whole-paper outline call held up at 134k tokens, so the hierarchical outline variant stays unbuilt.

Paper reader and figures

The paper's home view is now the paper: the stored LaTeX compiled with TeX Live 2025 (latexmk, pdfLaTeX) in a no-network Vercel Sandbox with SyncTeX on, shown in PDF.js. SyncTeX maps every node's statement and proof lines to boxes on the page, so statements carry a faint overlay and a margin marker, a click in one selects its node, and selecting a node anywhere scrolls the PDF to it. Figures are cropped out of the compiled PDF (TikZ included), described by Opus 5.5 from the image, and shown wherever \ref{fig:…} appears. Design: 20261029_paper_reader/design.md; plan: § Post-v1: paper reader and figures.

  • Backfilled: eth, eth-e2e, eth-agent, sensitivity (no figures), unit-distance (2 TikZ figures), sunflowers-rao (2 PDF figures); every node anchored on all six. sunflowers-rao-agent holds the forced fallback.
  • Vision: $0.015–0.035 per figure (Opus 5.5). Descriptions match the images; one Rao figure description misplaced a petal's end relative to the outline V. No corpus paper has a data plot, so the chart path (axes, series, "unreadable" values) is tested with a mocked model only.
  • The chat does not know figure descriptions yet (it found the label by searching the source); see the plan for the suggested view_figure tool.

Post-sprint polish

Owner feedback after the sprints, all on the reading experience.

Equation and cross-references

\eqref, \ref, \cref and friends no longer print raw labels. Equations get a "(1.1)" link whose popover shows the equation in KaTeX with its section and source line; statement refs read "Lemma 6.3" and select the node. Numbering is extracted deterministically at finalize; existing digests were backfilled with $0 finalize-only re-runs.

Graph headlines and roles

Graph cards now say what each node establishes (a short headline, verb-first, "So …" for corollaries, "Defines …" for definitions) and, on a muted second line, its role for the results that use it. One graph-labels pass at the end of annotate writes them; all 19 digested papers were backfilled for $2.12.

Zoom UX, "feeds into" arrows, leaf tuck

A d3-zoom viewport replaced overflow scrolling: wheel and pinch zoom around the cursor, drag to pan, click to select with an animated glide, keyboard shortcuts (0 whole graph, 1 100%, F fit the chain, arrows to walk edges), a minimap, and level of detail when zoomed out. Arrows now point from a supporting node up to the result it feeds into. Leaves are tucked one layer under their lowest user so the drawing is narrower.

Chat tools

The paper chat can now look past the digest: read_node returns a node's verbatim statement and its proof text from the stored LaTeX (line-numbered, capped at 12k chars), search_paper searches the source, and trace / ancestors follow the dependency graph. Up to four tool rounds per answer; each call shows as a small muted row (spinner while running, error and stopped states, details on click). On ETH: "Quote the key step of the proof of lem:greedy-hashes" read the node and quoted lines 3468–3495; "Where is the √log n parameter chosen?" searched the source twice; "How does lem:sparse-checks lead to the main theorem?" traced the path. Warm turns cost $0.017–0.046 (gateway-reported).

  • Same structure under both methods. 100% statement recall everywhere, claim counts within 2, the same long proofs outlined, critique findings in the same range. The tier-1 golden passes under both.
  • Cost is a wash. Outline $3.68 vs $3.75, whole runs $18.95 vs $19.14. The agent wins when the long proofs are a small share of a large source (ETH −27%, logspace −19%) and loses otherwise (PFR +40%, intmult +36%).

Decision (implemented in server/utils/aiModels.ts): default method pipeline; agent at ≥ 200k tokens (AGENT_MIN_TOKENS), where one whole-paper Opus call nears the per-step ceiling. The threshold is an extrapolation: no corpus paper is that large yet. Profile default is unchanged: careful over 30 pages or 100k tokens, else standard.
